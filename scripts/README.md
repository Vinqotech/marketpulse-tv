# MarketPulse TV rendering

The public `Vinqotech/marketpulse-tv` repository contains only the renderer, not station secrets. GitHub repository dispatch carries an episode-scoped callback token and signed upload URLs. Do not print the event payload, upload it as an artifact, or commit it. Signed uploads expire after two hours. The workflow times out after 110 minutes.

The workflow copies `renderer/package.json` to the repository root, installs its dependencies with `npm install`, then runs `node scripts/render-briefing.mjs`. The GitHub runner uses CPU Kokoro and FFmpeg; no paid avatar, video or voice APIs are used. Public standard GitHub runners are normally free; GitHub plan and usage restrictions still apply. Cloud storage, bandwidth and a continuous RTMP host may cost money. A public repository does not make the station's Cloud data public.

The station assembles cleaned, source-credited facts deterministically. Before rendering, `broadcast_editor.py` uses the open-source Qwen2.5-3B-Instruct model locally on the GitHub CPU runner with greedy decoding to rewrite headlines and narration. A local NLI DeBERTa model removes unsupported sentences and checks headline support. No paid AI API is used. Model download and inference add runner time. Numeric, credit, copying and opening checks reject unsafe outputs; these checks are not a guarantee of semantic accuracy, so editorial review remains necessary. Source names and publication metadata stay outside speech; credits remain in the episode description. The Ready callback saves the rewritten text and actual segment timings. Clearly labeled educational samples remain labeled, and failed editorial validation stops rendering rather than silently broadcasting raw feed copy.

New episodes use the station's selected duration at approximately 145 words per minute, divided evenly between news and quantitative analysis: 4 minutes = 290/290 words, 6 = 435/435, 8 = 580/580. The news desk selects up to six top stories (four to six when available), preserving fewer verified stories rather than inventing news when sources are sparse. The CPU editor rewrites to each allocated word budget, within ten percent, and appends one conversational act transition. Unsafe or under-budget rewrites fail rather than silently reverting to feed readouts.

`quantitative-showdown.mjs` selects sector-related assets or deterministically rotates major pairs. During the GitHub run it fetches five-year Yahoo Finance public daily chart JSON, retries failures, and requires USD prices and valid anniversary coverage. Latest available daily close is not a live quote. One- and five-year returns and hypothetical $10K growth use adjusted prices; drawdown scans adjusted closing highs and subsequent lows. Results are before taxes and trading costs and depend on provider adjustment accuracy. BTC is paired with explicitly labeled GLD, a gold ETF, not fabricated spot GOLD. No paid API or key is required; availability and usage rights are not guaranteed. A data outage fails the render with a visible error, never synthetic metrics. The verdict equally weights one-year return, five-year return and shallower drawdown, not future investment suitability.

Kokoro uses Bella (`af_bella`) at normal 1.0x speed. Each story is immediately normalized to 48 kHz stereo PCM, with less than one frame of trailing padding. Act 1 and Act 2 are assembled separately as WAV and exported as 48 kHz stereo AAC `.m4a` files. The WAV acts are measured and concatenated losslessly, avoiding AAC encoder-delay gaps. `act1DurationFrames` and `totalDurationFrames` drive Remotion `calculateMetadata` at 30 FPS; the split-screen asset scorecard appears on the precise frame Act 2 begins. Word budgets approximate duration; natural speech is never stretched to force an exact clock length or exact 50/50 seconds. The final MP4 mux maps the combined PCM into 48 kHz stereo AAC. The Ready callback stores both acts, rewritten takeaways, measured timing and the verified metrics. Existing episodes are not changed and must be regenerated to use two acts.

An anchor image has subtle motion and a voice-reactive visualization, not synthetic lip-sync. Preview charts are illustrative; no market quotes are fabricated. The video bug says BULLETIN, not LIVE, because it is recorded. Reuters' retired public RSS endpoints are not seeded; BBC World is the world-news replacement. Check each feed's syndication and rebroadcast rights before public distribution.

Publish the station before dispatching renders: GitHub must reach the callbacks and media. Sign in, save settings, and generate a bulletin. Saved episodes stay scheduled on dispatch failure with a visible error; rendered episodes become ready only after verified uploads. A separate always-on host must run `stream-247.sh`; GitHub Actions does not provide an unlimited 24/7 RTMP server. Restart the stream process to pick up a changed rotation.
