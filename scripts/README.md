# MarketPulse TV rendering

The public `Vinqotech/marketpulse-tv` repository contains only the renderer, not station secrets. GitHub repository dispatch carries an episode-scoped callback token and signed upload URLs. Do not print the event payload, upload it as an artifact, or commit it. Signed uploads expire after two hours. The workflow times out after 110 minutes.

The workflow copies `renderer/package.json` to the repository root, installs its dependencies with `npm install`, then runs `node scripts/render-briefing.mjs`. The GitHub runner uses CPU Kokoro and FFmpeg; no paid avatar, video or voice APIs are used. Public standard GitHub runners are normally free; GitHub plan and usage restrictions still apply. Cloud storage, bandwidth and a continuous RTMP host may cost money. A public repository does not make the station's Cloud data public.

The station assembles cleaned, source-credited facts deterministically. Before rendering, `broadcast_editor.py` uses the open-source Qwen2.5-3B-Instruct model locally on the GitHub CPU runner with greedy decoding to rewrite headlines and narration. A local NLI DeBERTa model removes unsupported sentences and checks headline support. No paid AI API is used. Model download and inference add runner time. Numeric, credit, copying and opening checks reject unsafe outputs; these checks are not a guarantee of semantic accuracy, so editorial review remains necessary. Source names and publication metadata stay outside speech; credits remain in the episode description. The Ready callback saves the rewritten text and actual segment timings. Clearly labeled educational samples remain labeled, and failed editorial validation stops rendering rather than silently broadcasting raw feed copy.

Kokoro uses the alternative American-English Bella voice (`af_bella`) at normal 1.0x speed and is normalized to 48 kHz stereo PCM WAV immediately after synthesis. Short segments receive trailing silence; long segments extend their video timeline so speech is neither sped up nor cut off. Remotion and the final H.264/AAC mux both use 30 FPS, with the normalized WAV mapped directly into the final MP4. An anchor image has subtle motion and a voice-reactive visualization, not synthetic lip-sync. Preview charts are illustrative; no market quotes are fabricated. The video bug says BULLETIN, not LIVE, because it is recorded. Reuters' retired public RSS endpoints are not seeded; BBC World is the world-news replacement. Check each feed's syndication and rebroadcast rights before public distribution.

Publish the station before dispatching renders: GitHub must reach the callbacks and media. Sign in, save settings, and generate a bulletin. Saved episodes stay scheduled on dispatch failure with a visible error; rendered episodes become ready only after verified uploads. A separate always-on host must run `stream-247.sh`; GitHub Actions does not provide an unlimited 24/7 RTMP server. Restart the stream process to pick up a changed rotation.
